# 03_supabase_feedback.md

## 개요
이 문서는 **Supabase** 를 이용한 피드백 저장 및 조회 기능을 상세히 설명합니다. 로그인 없이 익명으로 피드백을 제출하고, 최신순으로 화면에 표시합니다. Supabase 키가 설정되지 않은 경우, 로컬 `localStorage` 를 사용한 **Mock** 구현으로 대체됩니다.

## 테이블 스키마
```
CREATE TABLE feedback (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  content TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT now()
);
```
> **주의**: 테이블 정의 파일은 `supabase/migrations/001_create_feedback_table.sql` 에 저장됩니다.

## RLS (Row Level Security) 정책
```sql
-- 모든 사용자에게 INSERT, SELECT 권한을 부여 (익명 접근 허용)
ALTER TABLE feedback ENABLE ROW LEVEL SECURITY;
CREATE POLICY "allow_anonymous" ON feedback FOR ALL USING (true);
```
> **NOTE**: 실제 서비스 배포 시에는 악의적인 스팸 방지를 위해 추가 검증 로직을 적용해야 합니다.

## 클라이언트 코드 (`supabaseClient.js`)
```javascript
// 환경 변수에서 Supabase URL/Anon Key 를 읽어 초기화합니다.
const SUPABASE_URL = window.__ENV?.SUPABASE_URL;
const SUPABASE_ANON_KEY = window.__ENV?.SUPABASE_ANON_KEY;

let supabase = null;
if (SUPABASE_URL && SUPABASE_ANON_KEY) {
  supabase = supabase.createClient(SUPABASE_URL, SUPABASE_ANON_KEY);
} else {
  console.warn('Supabase 환경 변수가 없으므로 Mock 로컬 스토리지를 사용합니다.');
}

export function getSupabaseClient() {
  return supabase;
}
```

## 피드백 전송 로직 (`app.js` 내 `submitFeedback`)
```javascript
async function submitFeedback(event) {
  event.preventDefault();
  const content = feedbackInput.value.trim();
  if (!content) return showToast('피드백을 입력해주세요.', 'error');

  const client = getSupabaseClient();
  if (client) {
    const { error } = await client.from('feedback').insert({ content });
    if (error) return showToast('피드백 전송 실패', 'error');
  } else {
    // Mock: localStorage 배열에 저장
    const stored = JSON.parse(localStorage.getItem('feedback') || '[]');
    stored.unshift({ content, created_at: new Date().toISOString() });
    localStorage.setItem('feedback', JSON.stringify(stored));
  }
  feedbackInput.value = '';
  loadFeedbackList();
  showToast('피드백이 전송되었습니다.', 'success');
}
```

## 피드백 목록 조회 (`loadFeedbackList`)
```javascript
async function loadFeedbackList() {
  const client = getSupabaseClient();
  let rows = [];
  if (client) {
    const { data, error } = await client
      .from('feedback')
      .select('content,created_at')
      .order('created_at', { ascending: false })
      .limit(20);
    if (!error) rows = data;
  } else {
    rows = JSON.parse(localStorage.getItem('feedback') || '[]');
  }
  feedbackList.innerHTML = rows
    .map(r => `<li>${escapeHtml(r.content)}<br><small>${new Date(r.created_at).toLocaleString()}</small></li>`)
    .join('');
}
```
> **보안**: `escapeHtml` 함수를 사용해 HTML 인젝션을 방지합니다.

## 테스트 시나리오
| 번호 | 행동 | 기대 결과 |
|------|------|-----------|
| 1 | 피드백 입력 후 전송 | 리스트 최상단에 새 피드백이 즉시 표시되고 toast `success` 가 나타남 |
| 2 | Supabase 키가 없는 경우 | 로컬스토리지에 저장되고 새로고침 시에도 유지 |
| 3 | 다중 사용자가 동시에 전송 | 최신순 정렬 유지, 충돌 없음 |

> [!TIP] 실제 서비스에서는 **reCAPTCHA** 등 스팸 방지 수단을 추가하는 것을 권장합니다.
